## Evidence and tradeoffs

Final source validation at 3a34868: native Ubuntu/macOS (Python 3.11 and 3.13) each **326 passed, 4 skipped**; native Windows both versions **323 passed, 7 skipped**; separate live Docker **3 passed**. All seven CI jobs passed. Local WSL: **326 passed, 4 skipped**. Local Windows: **321 passed, 2 failed, 7 skipped**, with the unchanged symlink-privilege fixture failures. The full source Ruff check, installed-wheel CLI/demo and stdio MCP handshake passed. The original 99-scenario module still contains and executes 99 cases.

New tests cover adapter conformance, isolated proposal assets, runtime dollars, concurrent ledger settlement, state recovery, strict review gates, real HTTP, plugins, regression/no-progress sentinels and adversarial review findings. No original test was deleted, weakened or marked xfail. Pre-fix review reproductions are retained separately from final regression artifacts; they are not counted as passing runs.

The detached snapshots, SQLite checkpoints and fresh full suite add wall-time overhead on tiny tasks. The measured offline benchmark cannot establish a dollar-saving policy or model-quality improvement. No paid provider run was made; actual provider dollars are unknown/not applicable for deterministic fixtures, and development-assistant billing is unknown. No fabricated zero-dollar efficiency ratio is reported.

No hard gateway capability is advertised. Docker is optional and never silently falls back. Host mutation requires an unsafe grant. Raw command exit/output checks establish the declared observations, not proof that arbitrary imported code cannot subvert a language's test framework. Stronger black-box or external verifiers can be registered as trusted integrations.

## Next two engineering priorities

1. Run an explicitly budget-authorized live adapter study with pinned CLI/model versions and invoice reconciliation; test optional gateway enforcement end to end before any hard-limit claim.
2. Expand independent black-box/browser acceptance and crash/application recovery coverage, including transactional application, detached-child containment and a reviewed untrusted-plugin strategy.

The [known limitations](KNOWN_LIMITATIONS.md) are part of the handoff. This passing subset is reviewable software, not a declaration that all production release gates have passed.
