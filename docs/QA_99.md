## Reproduced issues, fixed in source

1. Reject empty strings in `builder.argv` during validation.
2. Honor the `contains` assertion for command output, including negative cases and chunk boundaries.
3. Require explicit `--allow-network` before non-local HTTP/browser checks; reject an external browser step when not approved.
4. Validate negative token limits and negative output budgets; guard against duplicate budget settlements.
5. Settle reserved model quota when the provider connection raises a low-level `OSError`.
6. Reject invalid negative/zero iteration overrides at the engine boundary, not only the CLI.
7. A verification that completes after the overall deadline must not report `passed`.
8. Treat blocked/missing explicitly requested source evidence as `needs_review`, even when all local checks pass.
9. Do not automatically follow a research-source redirect (potential destination change/SSRF risk).
10. Validate browser `fill` values and URL-regex syntax before running.

## What remains unverified

- Live browser automation under an environment that permits Chromium navigation.
- Actual Claude Code, OpenCode, Codex, and other external builder/provider integration and billing limits.
- OS-enforced sandboxing or prompt-injection resistance; a folder path is **not** a security boundary for a subprocess.
- Public internet idea validation and reliable freshness of external datasets.
- Performance under concurrency, live production traffic, cross-platform timeouts, and full security penetration testing.

This release records what was genuinely tested and does not claim production readiness or unlimited correctness.
